# AI文本编辑（MT AI 插件）

在 **MT 管理器**的文本编辑器里直接调用任意常见 AI 接口，让 AI 帮你改文件。

> 打开文件 → 点编辑器顶部「**铅笔**」→ 「**AI 编辑**」→ 输入指令 → 发送 → 预览确认 → 一键**应用**。

---

## 功能

- **任意 AI 接口**：支持 OpenAI 兼容（DeepSeek / 通义千问 / Kimi / 智谱 / SiliconFlow / Ollama / 中转站）+ Claude + Gemini，内置 10 个服务商预设，也可自定义地址；
- **三种作用范围**：整个文件 / 选中文本 / 光标处插入，按需选择**省 tokens**；
- **流式输出**：结果实时显示，可随时停止；
- **Plan / Act 双模式**：先让 AI 分析出方案（只读），点「执行方案」一键切换到 Act 并按方案自动执行写入；
- **连续对话**：AI 回答后输入框自动清空，直接输入下一条即可追问，AI 记住上下文直到关闭窗口；
- **对话导出**：一键把完整会话导出为文本文件（目录 / 文件名可自定义）。

## 安装要求

- MT 管理器 **2.26.3+** 且为 **VIP**（插件系统 v3 需要）；
- 下载 `.mtp` 插件包 → MT 侧边栏 → 工具 → **插件管理** → 安装。

## 快速开始（三步）

1. **先配置 AI（必做）**：插件管理 → 找到「AI文本编辑」→ 点「**设置**」→ 选服务商、填 API Key、确认模型名（地址可留空，自动用默认）。
2. **打开对话框**：用 MT 打开任意文件 → 点顶部「铅笔」→ 点「**AI 编辑**」（找不到就先在「自定义」分组把它拖到常用位）。
3. **开始编辑**：选作用范围 → 输入指令（如「给这段代码加注释」「翻译成英文」）→ 发送 → 确认后点「**应用**」写回文件。

## 使用提示

- **能省 tokens 就省**：「整个文件」发送全文最费，「选中文本」只发选中片段最省，「光标处插入」只发光标前后一小段。大文件建议先选中要改的部分；
- **应用前可改**：AI 输出会显示在预览框，可直接手动修改调整后再「应用」或「复制」；
- **重要操作先用 Plan**：想保守一点就先切 Plan 看方案，再切 Act 执行。

## 常见问题

- **找不到「AI 编辑」入口**：点「铅笔」后没有？在「自定义」分组把它拖到常用位置即可；
- **报 401**：API Key 错误或没权限；**报 404**：接口地址少了/多了 `/v1`，或模型名不对；
- **担心 token 费用**：优先用「选中文本」模式，避免对超大文件用「整个文件」；
- **Key 安全吗**：只保存在本机，卸载即删除，仅随请求发送给你配置的接口地址。
