[size=4][b]⚙️ 快速开始（三步）[/b][/size]
[b]① 先配置 AI（必做）[/b]
插件管理 → AI文本编辑 → 设置：
[list]
[*]服务商：选预设（如 DeepSeek）或「自定义」
[*]API Key：填写密钥（Ollama 本地可留空）
[*]默认模型：如 deepseek-chat（接口地址留空会自动用预设）
[/list]

[b]② 打开「AI 编辑」对话框[/b]
打开任意文本文件 → 点编辑器[b]顶部的铅笔按钮[/b] → 在菜单里找「[b]AI 编辑[/b]」
[color=#e74c3c]👉 找不到？先在「自定义」分组里把「AI 编辑」拖到常用（可用）位置即可[/color]

**[b]③ 让 AI 编辑[/b]
选作用范围 → 输入指令（如「给这段代码加注释」「翻译成英文」）→ 点「发送」→ 预览 → 点「应用」

[color=#2ecc71][b]💡 省 token 小技巧[/b][/color]
[size=3][list]
[*]三种作用范围会把不同内容发给 AI：[b]整个文件[/b]（全文，最费 token）/ [b]选中文本[/b]（只发选中的片段，最省）/ [b]光标处插入[/b]（只发光标附近一小段）
[*]大文件建议[b]先选中要改的部分[/b]，用「选中文本」模式，可显著节省上传 tokens
[*]AI 返回的输出在预览框里是[b]可编辑[/b]的——应用前可以手动修改调整，再点「应用」写回
[/list][/size]

[size=4][b]❓ 常见问题[/b][/size]
[b]Q1：装了插件但编辑器菜单里找不到？[/b]
进「工具 → 插件管理」确认已装「AI文本编辑」；再确认文件可写（只读会隐藏菜单）；最后在铅笔按钮的「自定义」里把「AI 编辑」拖出来。

[b]Q2：发送后报 401 / 404？[/b]
401 一般是 API Key 错误；404 一般是接口地址或模型名不对，对照上表检查。

[b]Q3：为什么必须 VIP？[/b]
MT 插件系统 v3 的官方要求（MT 2.26.3+ 且 VIP 才能安装/运行插件），与插件作者无关。

[b]Q4：API Key 安全吗？[/b]
只保存在本机插件专用存储里，卸载即删除；请求仅发给你在设置里填的接口地址。

[b]Q5：怎么更换图标 / 自定义模型列表？[/b]
开源地址提供完整工程与 GitHub Actions 云构建，改 ProviderRegistry.java 的模型列表、替换 resources/icon.png 后重新打包即可。
