# 开发日志

> 记录 AI文本编辑（MT-AIedit）的版本演进。

- **v1.0.0** 首发：编辑器内 AI 编辑——流式输出、三种作用范围、预览确认应用；支持 OpenAI 兼容 + Claude + Gemini 协议，10 个服务商预设；完整设置界面；中英文语言包。
- **v1.0.1** 插件更名为「AI文本编辑」，完善使用说明（先配置 AI、铅笔按钮入口、自定义拖出）。
- **v1.0.2** 优化关于界面展示（社区官网 / QQ频道 / 群号入口），应用/复制读取修改后内容，流式输出滚动跟随修复。
- **v1.0.3** API 密钥掩码显示，新增 tokens 用量显示（可选开关），关于页标注作者。
- **v1.0.4** 修复「整个文件」功能无输出 Bug（思考型模型占满 max_tokens），默认上限提升至 8192，思考进度 / 截断提示。
- **v1.0.5** 优化「整个文件」模式：上传进度提示、过大文件保护、打开不再预读全文卡顿。
- **v1.1.0** 新增多套配置方案（3 套秒切）、多轮连续对话、Token 预估、系统提示词预设、停止后内容保留。
- **v1.1.2** 修复方案选择功能界面错乱，配置方案独立成行并显示服务商名，「新对话」改为「继续对话」。
- **v1.2.1** 新增 Plan / Act 双模式（Plan 只读分析 / Act 执行写入，切换自动继承上下文）。
- **v1.2.2** 发送按钮移至指令框右侧，打开不自动弹输入法，Plan / Act 只读输出拦截与提示。
- **v1.2.3** UI 优化：模型选择与配置方案收进「配置」弹窗，主界面更简洁。
- **v1.2.4** 设置 / 关于移入配置弹窗，配置按钮置于「停止 / 继续对话」之间，Plan 模式不输出原文，修复指令输入框下半部分消失。
- **v1.3.0** 新增对话导出（复制按钮旁，导出完整会话为文本文件）；发送按钮绿色高亮；设置新增默认启动模式（Plan/Act）自定义。
- **v1.3.1** 复制 / 导出 / 应用 / 关闭合并为底部一行文字链接；导出升级为独立弹窗（可指定目录与文件名格式，目录自动记忆，支持 {title}/{date}/{time} 占位符与实时预览）；移除论坛发帖文案精简体积。
- **v1.3.2** 底部操作区美化（分割线 + 留白）；Act 输出结束后「应用」变绿高亮；导出目录支持常用目录快捷选择（保留手动输入）。
- **v1.3.9** 移除 Plan 结尾「切换到 Act」引导语；新增「执行方案」按钮（Plan/Act 并排）：一键切换 Act 并按历史自动执行，Act 模式下按钮禁用。
- **v1.3.8** 调整 Plan 引导语检测词：去掉「需要补充」否定信号（含该词的方案也会正常追加引导）。
- **v1.3.8** Plan 模式引入结构化信号 [SWITCH_TO_ACT]：AI 认为方案就绪时在结尾输出该标记，插件检测后自动保证引导语（移除标记、不重复追加）；无信号时回退启发式判断。
- **v1.3.7** Plan 模式切换引导改为代码兜底：输出含可执行方案（如【修改方案】/改法/涉及位置）且信息充足时，自动在结尾追加「切换到 Act 模式」引导；无方案/信息不足时不加，不再依赖 AI 自觉。
- **v1.3.6** Plan 模式结尾引导改为条件触发：仅当 AI 给出具体可执行方案时才提示切换到 Act 模式；无方案（如指令不明确）时不出现。
- **v1.3.5** Plan 模式参考 Cline 交互：AI 讲清方案后，结尾引导用户切换到 Act 模式自动开始生成需要的内容。
- **v1.3.4** 移除「继续对话」按钮：AI 完成自动清空输入框，再次输入即自动继续多轮对话（保留历史）。
- **v1.3.3** 目录快捷选择后弹窗自动关闭；优化三种作用范围的全文读取与提示词（光标插入只读光标附近窗口，选中文本不再读取全文，节约输入 tokens）。

## 特别说明

- 插件支持**多轮对话**：对话框中点击「继续对话」会清空输入框但保留对话历史与 AI 输出，可直接输入下一条指令，AI 会记住之前的上下文（记忆直至关闭窗口）。
- Plan / Act 切换按钮位于 AI 输出框下方。
- 底部操作：复制 / 导出 / 关闭 / 应用（应用在最右侧，Act 输出完成后变绿高亮）。
