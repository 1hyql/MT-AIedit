# 【插件】AI文本编辑 v1.0.2 —— 在 MT 文本编辑器里调用任意 AI 接口，流式编辑文件

> 支持 OpenAI / DeepSeek / 通义千问 / Kimi / 智谱 GLM / SiliconFlow / Ollama / Claude / Gemini / 自定义接口
> 需要 MT 管理器 **2.26.3+** 且 **VIP**（插件系统 v3 要求）

## ✨ 功能特性

- 📝 **编辑器内直达**：文本编辑器顶部「编辑」菜单一键打开，无需切出应用
- ⚡ **流式输出**：AI 结果边生成边显示，可随时停止
- 🎯 **三种作用范围**：整个文件 / 选中文本 / 光标处插入
- ✅ **预览确认**：应用前可反复查看/修改，点「应用」才写回文件并自动保存
- 🔧 **任意 AI 接口**：10 个服务商预设 + 「自定义」，协议全覆盖
- 🧼 **智能清理**：自动剥离 AI 输出首尾的代码块围栏
- 🔐 **Key 本地保存**：仅存本机，卸载即删

## 📥 安装

1. 下载附件中的 `.mtp` 文件（或 GitHub Actions 产物）
2. 传到手机 → MT 管理器 → 侧边栏 → **工具 → 插件管理**
3. 点右上角 **安装** → 选择 `.mtp` → 完成

> 插件 ID：`com.tec.aiedit` ｜ 版本：v1.0.2

## ⚙️ 快速开始（三步）

**① 先配置 AI（必做）**
插件管理 → AI文本编辑 → **设置**：
- 服务商：选预设（如 DeepSeek）或「自定义」
- API Key：填写密钥（Ollama 本地可留空）
- 默认模型：如 `deepseek-chat`（接口地址留空会自动用预设）

**② 打开「AI 编辑」对话框**
打开任意文本文件 → 点编辑器**顶部的铅笔按钮** → 在菜单里找「**AI 编辑**」
> 👉 找不到？先在「**自定义**」分组里把「AI 编辑」拖到常用（可用）位置即可

**③ 让 AI 编辑**
选作用范围 → 输入指令（如「给这段代码加注释」「翻译成英文」）→ 点「发送」→ 预览 → 点「应用」

💡 **省 token 小技巧**
- 三种作用范围发给 AI 的内容不同：**整个文件**（全文，最费 token）/ **选中文本**（只发选中片段，最省）/ **光标处插入**（只发光标附近一小段）
- 大文件建议**先选中要改的部分**用「选中文本」模式，显著节省上传 tokens
- AI 返回的输出在预览框里是**可编辑**的——应用前可手动修改调整，再点「应用」写回

## ❓ 常见问题

**Q1：装了插件但编辑器菜单里找不到？**
答：进「工具 → 插件管理」确认已装「AI文本编辑」；再确认文件可写（只读会隐藏菜单）；最后在铅笔按钮的「自定义」里把「AI 编辑」拖出来。

**Q2：发送后报 401 / 404？**
答：401 一般是 API Key 错误；404 一般是接口地址或模型名不对，对照上表检查。

**Q3：为什么必须 VIP？**
答：MT 插件系统 v3 的官方要求（MT 2.26.3+ 且 VIP 才能安装/运行插件），与插件作者无关。

**Q4：API Key 安全吗？**
答：只保存在本机插件专用存储里，卸载即删除；请求仅发给你在设置里填的接口地址。

**Q5：怎么更换图标 / 自定义模型列表？**
答：开源地址提供完整工程与 GitHub Actions 云构建，改 `ProviderRegistry.java` 的模型列表、替换 `resources/icon.png` 后重新打包即可。
